### Contribution

there are many ways to contribute to this project:
- create, complete and document the structures or the classes
- split the assembly files
- decompile them into c++ using [objdiff](https://github.com/encounter/objdiff) and/or [decomp.me](https://decomp.me)
- unpack the binary assets into readable common formats (example: `.pac -> .png`, `.dat -> .csv or .json`)
- write tools
